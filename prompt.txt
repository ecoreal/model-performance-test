请创建一个现代化的"个人生产力仪表板"单页面应用，使用单个HTML文件实现。

【核心功能要求】

1. 番茄钟计时器
   - 可自定义工作时长（默认25分钟）和休息时长（默认5分钟）
   - 带有开始/暂停/重置按钮
   - 进度环形显示（或进度条）
   - 计时结束时有视觉和声音提示
   - 显示当前是工作模式还是休息模式

2. 每日任务列表（To-Do List）
   - 可添加新任务（回车键快速添加）
   - 可删除任务
   - 可标记任务为完成/未完成
   - 显示已完成任务数量统计
   - 支持本地存储（localStorage），刷新页面后数据保持

3. 习惯追踪器
   - 显示最近7天的打卡情况
   - 可视化展示（如方格打卡图或日历视图）
   - 点击当天可打卡/取消打卡
   - 显示连续打卡天数
   - 数据持久化存储

4. 励志名言模块
   - 页面加载时随机显示一条励志名言
   - 提供"换一条"按钮
   - 至少包含10条不同的名言

【技术要求】

- 使用原生HTML、CSS、JavaScript实现
- 可使用Tailwind CSS CDN或纯CSS，不使用其他外部库
- 响应式设计，完美适配手机（375px）、平板（768px）和桌面端（1024px+）
- 所有数据使用localStorage持久化存储
- 代码结构清晰，带有适当的注释
- 遵循现代Web开发最佳实践

【UI/UX设计要求】

1. 视觉设计
   - 采用现代化设计风格
   - 使用柔和的配色方案（建议：渐变背景 + 高对比度文字）
   - 卡片式布局，每个功能模块独立成卡片
   - 使用圆角、阴影、毛玻璃效果等现代视觉元素
   - 图标使用Unicode emoji或SVG

2. 动画效果
   - 按钮hover和点击时有平滑过渡
   - 任务添加/删除有淡入淡出动画
   - 番茄钟进度有平滑动画
   - 页面加载有优雅的入场动画

3. 交互体验
   - 所有交互都有即时的视觉反馈
   - 移动端优化触摸操作（按钮大小≥44px）
   - 表单验证和错误提示友好
   - 使用合理的spacing确保内容不拥挤

【加分项（可选）】

- 深色/浅色主题切换功能
- 键盘快捷键支持（如：N键新建任务、Space暂停/开始）
- 番茄钟完成次数统计和可视化
- 任务优先级标记（高/中/低）
- 数据导出为JSON功能
- 自定义主题颜色
- 周/月的习惯完成率图表
- 任务分类/标签功能
- 动态背景效果（粒子、波浪等）

【输出要求】

请生成完整的HTML文件，包含以下结构：
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <!-- meta, title, styles -->
</head>
<body>
    <!-- 完整的应用UI -->
    <script>
        // 完整的JavaScript逻辑
    </script>
</body>
</html>
```

代码要求：
- 生成的HTML文件可以直接在浏览器中打开使用
- 不依赖任何外部文件（除了可选的CDN）
- 代码格式规范，缩进统一
- 关键逻辑添加中文注释

请开始生成代码。
